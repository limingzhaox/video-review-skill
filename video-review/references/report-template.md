# 诊断报告模板（步骤 4 输出）

## 命名规则

- 视频文件名有语义（如 `国富论第二册第3章.mp4`）→ `<文件名去扩展名>-诊断报告.md`
- 文件名是随机哈希/无意义字符 → 用视频主题命名，如 `《国富论-节俭悖论》-诊断报告.md`
- 存到用户当前工作目录，报告生成后用文件呈现工具交付，对话里只给摘要

## 反 AI 味写作规范（写报告时必须遵守）

1. 一句话开头结论要**尖锐具体**，不许是"整体不错但有些优化空间"这种废话
2. 每条问题四元组齐全：问题 / 证据（时间戳或帧）/ 影响指标 / 改法（可直接用的话术）。缺证据的问题删掉
3. 禁词：赋能、抓手、闭环、链路、颗粒度、建议加强、可以考虑、某种程度上、值得关注
4. 改写话术必须口语化、念得出口；写完自己默念一遍，磕绊就重写
5. 先给结论再给依据，用户要的是判断不是过程
6. 保留项（做对的）必须列，防止用户改片时把好资产改掉

## 报告骨架

```markdown
# 《{视频主题}》诊断报告

> 视频：{文件名} | 时长：{X分X秒} | 画面形式：{如"扁平插画+底部字幕"} | 诊断时间：{日期}

## 一句话结论

{尖锐、具体、一句话说清这条视频数据不好的根本原因}

## 问题清单（按严重度排序）

### P0-1. {问题标题}
- 证据：{时间戳 + 原文/画面描述}
- 影响：{2s跳出率 / 完播率 / 评论率 / 转发率}
- 改法：{具体到话术}

### P0-2. ...

### P1-1. ...

## 模块一 · 开头钩子诊断

现状拆解：
- 0-2s：{原文}
- 2-4s：{原文}
- 4-6s：{原文}
- 诊断：{命中了哪条禁忌、好资产埋在第几秒}

改写方案（2-3 版）：

**版本 A · {钩子类型}**
> 0-2s：「...」
> 2-4s：「...」
> 4-6s：「...」
为什么有效：{一句话}

## 模块二 · 整体框架核查

### 节奏曲线（操盘手视角，必画）

```
0:00-0:15  [悬念✅ 新信息✅] 开头钩子段
0:15-0:46  [空窗⚠️] 三件预告，无新信息 → 流失段，建议删除
...
```

空窗段逐段给处理方案（填充资产 or 压缩删除）。

### 时长压缩方案（不提拆条）

| 段落 | 现状 | 处理 | 节省 |
|------|------|------|------|
| 0:15-0:46 预告段 | 31s | 删，留一句过渡 | 28s |
| ... | | | |
| **合计** | | | **可压到 X 分 X 秒** |

### 结构改动方案（如涉及挪动炸裂点，逐个按四件套输出）

【结构改动】把 X 从 A:BB 提到 C:DD
- 为什么改：...
- 改成什么：...（逐秒话术，已过默念测试）
- 怎么衔接：...（前后过渡句原文）
- 原位置怎么补：...

### 其他问题

{按四元组列出 P1/P2 问题}

## 模块三 · 标题与封面

标题（3 版）：
1. 【利益承诺式】...
2. 【悬念反差式】...
3. 【身份代入式】...

封面大字：「...」

## 保留项（改片时别动）

- {做对的点 1}
- ...

## 下一步动作（Top 3，按优先级）

2. ...

```
